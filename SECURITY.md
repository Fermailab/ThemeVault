# Security Policy

The ThemeVault team takes the security of our extension and its users seriously. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

## Supported Versions

Security updates and fixes are actively provided for the following releases:

| Version | Supported |
| :--- | :--- |
| 1.x.x | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities through public GitHub issues or forum discussions.

To report a vulnerability:
1. Send an email to **[security@fermailab.dev](mailto:security@fermailab.dev)**.
2. Include a descriptive summary of the issue, affected components (e.g. content script injection, storage handling), and steps or proof of concept to reproduce.
3. We will acknowledge receipt of your report within 48 to 72 hours.
4. Maintainers will work with you to analyze, reproduce, and resolve the vulnerability prior to public release.

## Coordinated Disclosure

We kindly request that you give us adequate time to investigate and ship a security release before making details of the vulnerability public. Thank you for helping keep ThemeVault users safe!
